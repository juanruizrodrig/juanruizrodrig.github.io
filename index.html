Github automations

Aplicación de uso personal y no comercial que utiliza GitHub Actions para automatizar eventos de Google Calendar con la autorización expresa del titular de la cuenta.

Entre sus funciones se encuentran la creación y actualización de avisos meteorológicos y de los horarios de electricidad con menor precio, así como la sincronización de entrenamientos programados.

La aplicación solicita acceso a eventos de Google Calendar para consultarlos y, cuando sea necesario, crear, actualizar y eliminar eventos relacionados con estas automatizaciones.

No se ofrece como servicio público ni comercial.
