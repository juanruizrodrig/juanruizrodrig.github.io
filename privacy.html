Política de privacidad · Github automations

Actualizada: 1 de noviembre de 2026.

Responsable y finalidad

Github automations es una aplicación de uso personal administrada por el titular de la cuenta de Google autorizada. Contacto: juanruizrodrig@gmail.com.

Datos de Google utilizados

Con autorización explícita, la aplicación puede consultar datos de eventos de Google Calendar, como títulos, fechas, horas, descripciones, identificadores y otras propiedades necesarias para comprobar y sincronizar sus eventos. Los permisos OAuth concedidos pueden dar acceso a otros eventos del calendario, aunque las automatizaciones están diseñadas para gestionar únicamente los eventos que identifican como propios.

Uso de los datos

Los datos se utilizan para consultar, crear, actualizar, verificar o eliminar eventos relacionados con automatizaciones personales, como avisos de lluvia, periodos de menor precio eléctrico y entrenamientos. No se utilizan para publicidad, elaboración de perfiles comerciales ni venta de datos.

Procesamiento y almacenamiento

Las tareas se ejecutan mediante GitHub Actions y la API de Google Calendar. Las credenciales se guardan como secretos de los repositorios privados pertinentes de GitHub. Los registros de ejecución pueden contener información operativa sobre las automatizaciones y se conservan según la configuración del servicio. Los eventos permanecen almacenados en la cuenta de Google Calendar. Esta página pública no almacena datos de los eventos ni sus credenciales.

Compartición y conservación

Los datos no se comercializan ni se entregan a anunciantes. El procesamiento técnico se realiza mediante los proveedores necesarios, principalmente Google y GitHub, de acuerdo con sus condiciones. La conservación de registros y eventos depende de la configuración de dichos servicios y de las acciones del titular.

Control y revocación

El titular puede revocar los permisos OAuth en la configuración de seguridad de su cuenta de Google, deshabilitar los workflows de GitHub o eliminar los eventos gestionados. Para consultas se puede contactar por correo electrónico.

Cambios

La política se actualizará si cambian los usos de los datos o la configuración de la aplicación.
